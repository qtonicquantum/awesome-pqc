# Contributing to Awesome Post-Quantum Cryptography

Thank you for considering a contribution. This list is curated and opinionated; not every relevant resource will be accepted.

## Inclusion Criteria

See [docs/CRITERIA.md](docs/CRITERIA.md) for the full editorial criteria. In short, an entry must be:

- Stable, canonical, and primarily about post-quantum cryptography.
- Hosted on a recognizable standards body, government, vendor, or well-known open-source project domain.
- Reachable via a long-lived URL (no link shorteners, no tracking links).
- Described in a single factual sentence ending in a period.
- Free of editorial superlatives such as "amazing", "best", or "must-have".

## How to Add an Entry

1. Fork the repository and create a feature branch.
2. Add your entry to the appropriate section in `README.md`, preserving alphabetical order.
3. Format: `- [Name](README.md) — One-sentence factual description ending in period.`
4. Run `npx awesome-lint` locally and confirm it passes.
5. Open a pull request using the provided template.

## How to Report a Broken Link

Open an issue using the "Broken Link" template with the affected entry and the failure mode (404, redirect, certificate error).
